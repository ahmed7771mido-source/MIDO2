# MIDO shop (Flask + SQLite)

متجر كامل + لوحة تحكم. مفيش أي إعداد لداتا بيس: SQLite بتتعمل لوحدها في instance/mido.db.

## التشغيل
    python -m venv venv
    source venv/bin/activate        # ويندوز: venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

- الموقع:  http://localhost:5000
- الأدمن:  http://localhost:5000/admin
- أول تشغيل بيطبع في التيرمنال يوزر وباسورد الأدمن (افتراضي: admin + باسورد عشوائي).
  عايز باسورد بتاعك من الأول:  ADMIN_USER=xxx ADMIN_PASSWORD=yyy python app.py
- غيّر الباسورد من: الأدمن > إعدادات الموقع.

## اللي في الموقع
- ناف بار: الرئيسية + الأقسام (هوديز، تيشيرتات، جواكت، ساعات، وأي قسم تضيفه) + العروض + بحث + السلة
- أيقونات واتساب وفيسبوك وإنستجرام وتيليجرام فوق جمب الناف بار (بتظهر اللي لينكه متسجل في الإعدادات بس)
- بيانات المشاركة (Open Graph) وأيقونة الموقع: اللينك بيظهر بصورة واسم لما يتبعت على واتساب أو فيس
- جدول مقاسات في صفحة كل منتج، وصفحات: سياسة الاستبدال، عن البراند، تواصل معانا (بتتعدل من الأدمن)
- تقييمات وصور العملاء على المنتج (بتظهر بعد موافقتك)
- رسوم توصيل حسب المحافظة (اختياري) وبتتحدث لايف في صفحة الطلب
- تتبع الطلب: رقم الطلب + الموبايل
- صفحة منتج بصور متعددة، اختيار مقاس ولون وكمية
- سلة ثم صفحة إتمام الطلب (الاسم، الموبايل، المحافظة، العنوان بالتفصيل، ملاحظات) ثم تأكيد
- دفع عند الاستلام، ورسوم التوصيل من الإعدادات

## اللي في الأدمن
- تحليلات شهرية: عدد الطلبات، المبيعات، ربح المنتجات، المصاريف، صافي الربح، رسوم بيانية لآخر 12 شهر
- المنتجات الأكتر طلباً (الشهر المختار وعلى الإطلاق) وتوزيع حالات الطلبات
- المنتجات: رفع صور متعددة، مقاسات، ألوان، مخزون، سعر، تكلفة، سعر عرض (خصم)، إخفاء، تمييز
- الأقسام: إضافة وتعديل وترتيب (بتظهر في الناف بار)
- الطلبات: إشعار فوري داخل اللوحة (تنبيه + عداد) وتفاصيل كاملة لكل طلب وتغيير الحالة (جديد، مؤكد، في الطريق، تم التسليم، ملغي)
- المخزون بينقص مع كل طلب وبيرجع لو الطلب اتلغى
- المصاريف (إعلانات، تغليف...) بتتخصم من الربح
- إعدادات الموقع: النصوص، شريط الإعلان، واتساب، السوشيال، التوصيل
- إشعار تيليجرام لكل طلب جديد (اختياري، من إعدادات الموقع)
- طباعة فاتورة / ملصق شحن لكل طلب
- تصدير الطلبات والمصاريف والعملاء لـ Excel (CSV)
- تنبيه المخزون القليل في التحليلات (الحد من الإعدادات)
- قايمة العملاء وتصفية المتكررين (اتنين طلب أو أكتر)
- إدارة التقييمات (موافقة/إخفاء/مسح) ورسوم التوصيل والصفحات
- نسخة احتياطية: زرار في الإعدادات، أو  python backup.py  (تتجدول بـ cron / Task Scheduler)

## النشر
- تشغيل حقيقي: gunicorn app:app  (خلف Nginx مع HTTPS)، أو PythonAnywhere / Render / VPS
- الدومين + HTTPS: وجّه الدومين للسيرفر وفعّل شهادة (Let's Encrypt / Certbot أو من الاستضافة). بيانات المشاركة بتستخدم لينكات الصور من الدومين تلقائي.
- الكود بيعتمد على هيدرز X-Forwarded من Nginx (ProxyFix)، فخلّي Nginx يبعت X-Forwarded-Proto و X-Forwarded-Host
- متشغلش FLASK_DEBUG=1 على السيرفر
- Backup: انسخ instance/mido.db و static/uploads/ بشكل دوري
